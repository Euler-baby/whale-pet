# 鲸鱼娘桌宠 · whale-pet

Windows 10/11 x64 桌面常驻小伙伴，包含本地待办、项目和独立每日/每周打卡。当前公开版本为 **0.4.2**。无需账户或云服务，应用本身可离线使用。

## 下载与运行

在 [Releases](https://github.com/Euler-baby/whale-pet/releases) 下载：

- setup.exe：安装版，支持安装路径选择和快捷方式。
- portable.exe：便携版，放入一个新的可写文件夹运行；个人数据保存到该 EXE 旁的 data 文件夹。分享程序时只发送 EXE，勿发送 data。

安装包未签名，Windows 可能显示 SmartScreen 提示。请核对 Release 中的 SHA256SUMS.txt。Windows x64 以外平台未支持。

## 功能

- 透明置顶、透明区域穿透、拖动与位置记忆、托盘隐藏/恢复；点击开心、长按摸头、完成任务庆祝。
- 任务清单：今日/全部与分类独立，点击已选分类可取消；项目任务可以在统一列表展示。
- 完成任务留在列表划掉，可取消完成；搁置任务进入独立清单，停止提醒及头顶卡片，恢复保留原截止时间。
- 右下角加号打开新建面板；项目创建/编辑使用弹窗。
- 独立打卡：多个每日/每周项目，本机本地04:00换周期；每周期一次，无补卡、无连续天数统计，不依赖任务完成。
- 默认提醒时间支持截止前1–1440分钟，任务可覆盖；临近与到期分阶段去重，提醒卡约12秒。
- 右键/托盘可打开设置、任务清单和使用教程。任务窗口可最大化。

提醒依赖应用运行、宠物可见、30秒检查、免打扰与队列状态；不承诺系统通知或无条件准点。普通提醒在23:00–07:00静默处理。

## 数据与升级

任务、项目、打卡只保存在本机 JSON。首次读取旧v2任务数据时，先备份原tasks/settings，再迁移为v3；旧整体打卡被移除，不转换为新习惯。不要上传个人data、backups、日志或截图。

0.4.x 使用 tasks v3。回退0.3.3必须先退出新版、另存当前数据，再恢复同组原v2/settings备份，之后才启动旧版；不能把唯一v3文件交给旧版。详见 [数据与隐私](docs/PRIVACY.md)。

## 开发

使用 Node.js 24、pnpm 12.3.4：

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm verify
pnpm smoke
pnpm dist
```

源码使用 Electron、React、TypeScript；主进程负责存储，renderer仅经受校验的IPC访问。IPC2.0.0（31 invoke+1 event）。公开快照保留产品源码与测试，未携带作者本机历史、诊断环境或个人开发记录。
