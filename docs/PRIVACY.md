# 数据与公开范围

应用无需登录，不提供云同步、遥测或联网任务服务。安装版使用 Electron 的本地userData目录；便携版使用EXE旁data目录。

公开仓库仅含审核后的源码、必要构建配置、自动化测试与产品素材。首次公开使用单独的新Git历史，未包含开发机账户路径、旧提交作者邮箱、内部交接记录、运行日志、个人任务/设置/打卡或备份。发布附件仅为EXE、源码快照ZIP与校验和，不包含运行数据目录。

测试中的任务/项目为合成夹具，不是用户数据。路径 API、settings.json/tasks.json这些代码字符串描述运行机制，不代表仓库携带个人数据文件。

## 升级备份和回退

v2→v3前会在数据目录backups/pre-v3-*保存原tasks.v2.json、原settings.json（如果存在）和manifest.json。迁移成功才替换任务文件；旧整体打卡只留在原v2备份。

回退0.3.3：退出所有版本；另存当前v3及设置；核对同一备份组的manifest和哈希；恢复tasks.v2.json为tasks.json并配对恢复settings（原本不存在则按manifest恢复该状态）；最后启动旧版。回退会回到备份时刻，新版新增内容不会自动转换。不要把这些备份提交到GitHub。

## 提交问题

请先删除截图中的任务标题、备注、项目名、用户名和路径；不要提交data/backups、完整日志或令牌。公开Issue及附件会被其他人看到。
